# Carpeta de fotos de la galería

Coloca aquí las fotos que quieres mostrar en la sección **Galería**.

## Cómo hacerlo

1. Nombra tus fotos así: `1.jpg`, `2.jpg`, `3.jpg`, `4.jpg`, `5.jpg`, `6.jpg`
2. Súbelas a esta carpeta (`/images`).
3. Listo: aparecerán automáticamente en la galería y en el visor ampliado (lightbox).

## Notas

- Mientras no haya fotos, la galería muestra marcadores elegantes ("Foto 1", "Foto 2"…) para que el sitio se vea bien igual.
- Si quieres **más o menos de 6 fotos**, edita el array `PHOTOS` dentro de `index.html`
  (busca el comentario `✎ EDITAR: nº de fotos`).
- Formatos recomendados: `.jpg` o `.webp`. Optimiza las imágenes (máx. ~1600px de ancho)
  para que el sitio cargue rápido en el celular.
- Las fotos verticales (retrato) se ven mejor en la grilla.
